# Koloda Threads Bot

Бот для Threads-аккаунта @koloda_tm (koloda.ua). Работает бесплатно на GitHub Actions: запускается раз в 30 минут с 06:00 до 23:00 по Киеву.

Что делает:
- каждый день готовит 3 поста (Gemini: 4 варианта, фильтры, оценка редактора не ниже 7/10, проверка фактов поиском Google);
- присылает черновики в Telegram с кнопками «Опубликовать / Другой вариант / Пропустить»;
- публикует в Threads **только после кнопки владельца**, в своё время (утро, день, вечер), не чаще раза в 75 минут;
- каждый пятый пост продающий (с телефоном), остальные живые;
- раз в 7 дней сам продлевает токен Threads;
- о проблемах пишет в Telegram.

## Секреты (Settings → Secrets and variables → Actions → New repository secret)

| Имя | Что вставить |
|---|---|
| `THREADS_TOKEN` | долгоживущий токен Threads (User Token Generator в приложении Koloda Threads Bot) |
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `GEMINI_API_KEY` | ключ из aistudio.google.com |

Необязательно: `TELEGRAM_CHAT_ID` (если не задан, владельцем становится тот, кто первым напишет боту `/start`), `STATE_KEY` (любая длинная случайная строка для шифрования продлённого токена; по умолчанию используется токен Telegram).

## Команды в Telegram

`/status`, `/on`, `/off`, `/preview 3`, `/selftest`, `/help`. Чтобы поправить черновик, ответьте на него (Reply) своим текстом.

Бот просыпается раз в 30 минут, поэтому реакция на кнопки и команды приходит с задержкой. Быстрый запуск: Actions → bot → Run workflow (там же можно выбрать `selftest` или `preview`).

## Как устроено

- `bot/` код на Python без внешних библиотек; `tests/` автотесты (запускаются перед каждым запуском бота).
- `data/business.json` факты о бизнесе, `data/facts.json` проверенные факты про дрова, `data/rubrics.json` рубрики, `data/style.json` примеры тона.
- Состояние (расписание, черновики, опубликованные посты) хранится в ветке `state`, файл `state.json`. Токены там не лежат в открытом виде.
- Минуты Actions: около 35 запусков в день по ~1 минуте, это примерно 1100-1300 из 2000 бесплатных минут приватного репозитория.
