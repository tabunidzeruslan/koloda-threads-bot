# Проект: автопостинг Threads для koloda.ua

**Цель:** узнаваемость koloda.ua в Threads (@koloda_tm), чтобы киевляне писали и звонили. Бюджет 0.

**Источники:** THREADS-AUTOPOSTING-PLAYBOOK.md (архитектура Alter Bot), стратегия «Koloda.ua: план для Threads и соцсетей».

## Правила владельца
- Посты на украинском, 100-220 символов, крючок в первой строке, без эмодзи, хэштегов, списков, цен.
- Продающий пост 1 из 5, телефон 050 950 50 90 или «пишіть у дірект».
- Не выдумывать клиентов, случаи, цифры. Технические факты только проверенные.
- Без политики и войны, без паники про отключения, не высмеивать команду.
- Старт: публикация только после кнопки владельца в Telegram. Автопубликацию без кнопки не включать без его решения.
